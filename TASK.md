# TASK.md

## Суть проекта
Необходимо разработать локализованный веб-сайт для транспортной компании, специализирующейся на трансферах и поездках. Проект выполняется на базе Next.js с использованием App Router. 

## Ключевой функционал
1. **Лендинг:** Презентационная страница компании с описанием преимуществ и адаптивной версткой.
2. **Каталог услуг:** Визуальный блок или страница, демонстрирующая как минимум 4 типа поездок.
3. **Форма бронирования:** Интерактивная форма с валидацией в реальном времени. При отправке форма имитирует отправку на сервер, показывая лоадер и экран успеха, но никуда не сохраняет данные.
4. **Панель менеджера:** Внутренний интерфейс (без авторизации) для просмотра существующих поездок. Работает на изолированных мок-данных, включает поиск/фильтрацию по статусам и состояние "Empty State".
5. **Мультиязычность:** Переключение интерфейса между Английским (основной) и Русским языками. Текст не должен быть захардкожен.
6. **Юридические разделы:** Страницы Privacy Policy, Cookie Policy, Terms.

## Технический стек
* **База:** Next.js (App Router), React, TypeScript.
* **Стили:** Tailwind CSS v4 (использовать встроенные анимации и переходы).
* **Локализация:** `next-intl`.
* **Формы:** `react-hook-form` + `zod` (для построения схем валидации).
